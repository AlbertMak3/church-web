# Church Website Picture Resource Checklist
# 教會網站圖片資源清單

Keep the website wording, but use only wording and photographs of facilities without people.

保留網站文字內容，但只使用文字，以及沒有人物的設施照片。

## Overall Rule / 整體原則

**Use words and photographs of facilities without people only.**<br>
**只使用文字，以及沒有人物的設施照片。**

Do not use / 請勿使用：

- Portraits or leadership headshots / 個人肖像或領袖照片
- Congregation or group photographs / 會眾或團體合照
- Worship or ministry activities involving people / 有人物出現的崇拜或事工活動照片
- Children or youth photographs / 兒童或青少年照片
- Event photographs showing attendees / 顯示參加者的活動照片
- Historical photographs containing people / 有人物的歷史照片
- Distant people, silhouettes, hands, reflections, or blurred faces / 遠處人物、剪影、手部、倒影或經模糊處理的面孔
- Posters, artwork, wall photographs, or screens depicting people / 帶有人物形象的海報、圖畫、牆上照片或屏幕畫面
- Stock photographs containing people / 有人物的圖庫照片

**Do not upload photographs of people for editing or blurring. Keep them out of the website workflow entirely.**

**不要為了編輯或模糊面孔而上傳人物照片；整個網站製作流程都不應使用這些照片。**

## 1. Branding / 品牌識別

- [ ] Church logo without human figures / 沒有人物圖案的教會標誌
- [ ] Simplified logo or symbol / 簡化版標誌或圖形標記
- [ ] Light-background and dark-background versions / 淺色及深色背景版本
- [ ] Browser favicon / 瀏覽器分頁圖示
- [ ] Social-media profile image / 社交媒體頭像
- [ ] SVG and transparent PNG files / SVG 及透明背景 PNG 檔案

## 2. Homepage / 首頁

- [ ] Wide photograph of the empty auditorium / 空無一人的禮堂橫向照片
- [ ] Church exterior without pedestrians or worshippers / 沒有行人或會眾的教堂外觀
- [ ] Empty entrance lobby or welcome area / 空無一人的入口大堂或接待區
- [ ] Empty fellowship or community space / 空無一人的團契或社區活動空間
- [ ] Architectural feature that represents the church / 能代表教會的建築特色

Use a wide main-banner photograph with clear space for headline text.

首頁主視覺應使用橫向照片，並預留清晰空間放置標題文字。

## 3. New Here / Plan a Visit / 新朋友專區／聚會指南

- [ ] Church exterior from the street / 從街道拍攝的教堂外觀
- [ ] Main entrance / 教堂正門
- [ ] Empty reception or welcome counter / 空無一人的接待處或歡迎櫃檯
- [ ] Empty auditorium and seating / 空無一人的禮堂及座位
- [ ] Platform, pulpit, or altar area / 講台、講壇或祭壇區域
- [ ] Accessible entrance, ramp, and lift / 無障礙入口、斜道及升降機
- [ ] Accessible toilet and baby-care facilities, if relevant / 無障礙洗手間及育嬰設施（如適用）
- [ ] Empty children’s check-in area and classroom / 空無一人的兒童報到處及課室
- [ ] Car park, drop-off point, and bicycle parking / 停車場、上落客位置及單車停泊處
- [ ] Nearby station, bus stop, or transport signage without people / 沒有人物的鄰近車站、巴士站或交通指示牌照片
- [ ] Simple map or text-based directions / 簡明地圖或文字路線指引

Photograph rooms while they are completely empty.

應在房間完全沒有人時拍攝。

## 4. About Us and Beliefs / 關於我們及信仰理念

- [ ] Present church building without people / 沒有人物的現時教堂建築照片
- [ ] Historical building photographs containing no people / 沒有人物的歷史建築照片
- [ ] Architectural details / 建築細節
- [ ] Cross, pulpit, altar, or baptistry as part of the facility / 設施中的十字架、講壇、祭壇或洗禮池
- [ ] Church interior showing its layout / 顯示教堂格局的室內照片

Use written history, leadership biographies, and statements of faith without portraits.

教會歷史、領袖簡介及信仰告白均以文字呈現，不附人物照片。

## 5. Ministry Facilities / 事工設施

Use empty rooms instead of activity photographs.

以空無一人的房間照片取代事工活動照片。

Prepare where applicable / 如有相關設施，可準備：

- [ ] Children’s classroom / 兒童課室
- [ ] Nursery or baby-care room / 嬰幼兒室或育嬰室
- [ ] Youth room / 青少年活動室
- [ ] Adult classroom or Bible-study room / 成人課室或查經室
- [ ] Small-group meeting rooms / 小組聚會室
- [ ] Fellowship hall / 團契禮堂
- [ ] Prayer room / 祈禱室
- [ ] Music rehearsal room / 音樂練習室
- [ ] Library or resource room / 圖書館或資源室
- [ ] Counselling or pastoral-care room / 輔導或牧養關懷室
- [ ] Community-service facility / 社區服務設施
- [ ] Kitchen or refreshments area / 廚房或茶點區

Remove names, personal photographs, registration information, and other private details before taking pictures.

拍攝前應移除姓名、個人照片、報名資料及其他私人資訊。

## 6. Sermons and Events / 講道及活動

- [ ] Use text-based sermon-series graphics / 使用以文字為主的講道系列圖像
- [ ] Use an empty auditorium as the default sermon image / 以空無一人的禮堂作為預設講道圖片
- [ ] Use an empty venue photograph for event cards / 活動卡片使用空無一人的場地照片
- [ ] Use typographic event banners without pictures of people / 使用沒有人物圖片的文字活動橫幅
- [ ] Create English and Chinese versions separately / 分別製作英文及中文版本

Do not use speaker portraits, previous event photographs, or attendee photographs.

不要使用講員肖像、以往活動照片或參加者照片。

## 7. Prayer, Giving, and Pastoral Care / 祈禱、奉獻及牧養關懷

Prefer **text-only sections**.

這些部分建議**以文字為主**。

If an image is needed, use only / 如確有需要使用圖片，只可使用：

- [ ] Empty prayer room / 空無一人的祈禱室
- [ ] Empty counselling room / 空無一人的輔導室
- [ ] Empty chapel or quiet area / 空無一人的小禮堂或安靜區域
- [ ] Empty community-service facility / 空無一人的社區服務設施

Do not use photographs of praying people, hands, counselling sessions, or pastoral visits.

不要使用人物祈禱、手部、輔導會面或牧養探訪的照片。

## 8. Contact and Directions / 聯絡我們及交通指引

- [ ] Empty church exterior / 沒有人物的教堂外觀
- [ ] Main entrance close-up / 正門近照
- [ ] Nearby landmarks without people / 沒有人物的附近地標
- [ ] Empty car park and accessible route / 沒有人物的停車場及無障礙路線
- [ ] Public-transport facilities without people / 沒有人物的公共交通設施
- [ ] Simple map graphic / 簡明地圖
- [ ] Empty church office or reception area / 空無一人的教會辦公室或接待處

Avoid showing car number plates, addresses belonging to individuals, or private documents.

避免顯示車牌號碼、私人住址或私人文件。

## 9. Default and Sharing Images / 預設及分享圖片

- [ ] Default empty-auditorium image / 預設空禮堂圖片
- [ ] Default church-exterior image / 預設教堂外觀圖片
- [ ] Text-only event fallback graphic / 純文字活動備用圖像
- [ ] Social-sharing image using a facility photograph, **1200 × 630 px** / 使用設施照片製作 **1200 × 630 像素**的社交媒體分享圖片

## Photograph Requirements / 照片要求

- Main banner: landscape, at least **2400 px wide**<br>
  首頁主視覺：橫向，至少 **2400 像素寬**
- General facility photographs: **3:2 or 16:9**<br>
  一般設施照片：**3:2 或 16:9**
- Cards and thumbnails: **4:3 or 3:2**<br>
  卡片及縮圖：**4:3 或 3:2**
- Supply original, high-resolution JPG or PNG files<br>
  提供高解像度原始 JPG 或 PNG 檔案
- Check windows, mirrors, display screens, framed pictures, and noticeboards for people before publishing<br>
  發布前檢查窗戶、鏡子、屏幕、牆上照片及告示板，確認沒有人物或倒影
- Record the photographer, date, location, and usage permission<br>
  記錄攝影師、拍攝日期、地點及使用許可
- Provide English and Traditional Chinese captions and alternative text where needed<br>
  如有需要，提供英文及繁體中文圖片說明和替代文字
